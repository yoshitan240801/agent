# agent

LLMやフレームワークを活用した、AIエージェントの実装集です。Dify、Weaviate、OpenSearch、FastAPIなどを用いた具体的なユースケースを試しています。

---

## 🚀 収録プロジェクト・構成

本リポジトリでは、以下のような実践的なエージェントおよび検索システムの実装を公開しています。

| ディレクトリ / テーマ | 主要技術 | 概要 |
| :--- | :--- | :--- |
| **MultimodalSearchAgent_by_Weaviate_FastAPI_Dify** | Weaviate, FastAPI, Dify | ベクトルデータベースとFastAPI、Difyを組み合わせたマルチモーダル検索エージェントの実装 |
| **agent_for_data_science** | Python, Data Science Libraries | データサイエンスのワークフロー（分析・可視化など）をAIエージェントに自律実行させるための実験 |
| **agentic_search_with_dify_and_opensearch** | OpenSearch, Dify | OpenSearchの検索機能とDifyを連携させた、エージェント型検索（Agentic RAG）の構築 |

---

## 💻 実行環境・構成

*   **言語:** Python
*   **主要フレームワーク・ツール:** Dify, FastAPI, Weaviate, OpenSearch
*   **形式:** 各ユースケースごとに独立したフォルダ構成となっており、システム連携やエージェントワークフローの具体的な組み込み方を学ぶことができます。
